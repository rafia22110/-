## 2026-03-24 - Interactive List Accessibility & Reaction Drawer Focus
**Learning:** Converting interactive grid or list elements (like student cards) from standard 'div' containers to semantic 'button' elements automatically provides native tab focus, keyboard activation (via Enter/Space), and screen reader role identification. To preserve strict RTL visual layout alignment, pairing 'w-full' and 'text-right' is crucial for Hebrew/RTL languages. For hover-activated menus like the reaction picker, using 'group-focus-within/reactions:opacity-100' on the overlay container is necessary to ensure the menu is visible when sub-buttons receive keyboard focus.
**Action:** Always replace click-handlers on non-interactive semantic elements with native 'button' controls, ensure visual alignment handles RTL direction natively, and use 'group-focus-within' to expose hidden hover panels to keyboard focus.
