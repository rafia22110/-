## 2025-02-28 - [Accessible Stateful Buttons & Close Triggers in Metaverse dark mode]
**Learning:** In highly customized dark-themed 3D WebGL dashboards like the Metaverse Classroom, interactive floating HUD overlays and custom toggle controls (like the Metaverse Mode toggle) lack standard focus styling and visual accessibility cues. Icon-only elements (such as fullscreen toggle buttons and dismiss triggers) are completely opaque to screen readers unless given an explicit `aria-label`, correct stateful ARIA attributes (`aria-pressed`), and explicit keyboard focus visual boundaries.
**Action:** Always verify that every custom overlay trigger/button contains `type="button"`, state-specific labels, and the signature dark-theme focus rings with offset matching the dark backdrop `#050508` to satisfy both AAA keyboard visual accessibility and clean aesthetic presentation.
